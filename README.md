# ECE_ESP32_PCB_Recoso_EN1B

## Project Description

This project presents the design and development of a custom ESP32 Expansion PCB intended for embedded systems, IoT applications, and hardware prototyping. The PCB is designed to provide organized GPIO accessibility, stable power regulation, and easy integration of external modules and peripherals.

The board features an ESP32-WROOM-32 module footprint, USB Type-C power input, voltage regulation circuitry, GPIO breakout headers, and dedicated EN/BOOT controls for programming and debugging. The PCB layout was designed to maintain compactness while ensuring clean routing and reliable electrical performance.

The project development process includes schematic creation, PCB layout routing, component placement optimization, and 3D PCB visualization prior to fabrication.

## Features

- **ESP32-WROOM-32 Support**  
  Designed specifically for the ESP32-WROOM-32 module for Wi-Fi and Bluetooth applications.

- **GPIO Expansion Headers**  
  Provides accessible GPIO breakout pins for sensors, modules, and external devices.

- **USB Type-C Power Input**  
  Modern USB Type-C connector for reliable and convenient power delivery.

- **Integrated Voltage Regulation**  
  Includes onboard voltage regulator and filtering capacitors for stable operation.

- **EN and BOOT Controls**  
  Dedicated push-button connections for reset and firmware upload functions.

- **Power Indicator LED**  
  Onboard LED indicator for power status monitoring.

- **Compact PCB Design**  
  Organized and space-efficient PCB layout suitable for prototyping and educational use.
